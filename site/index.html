Why Lux.Agent

Headless C# engine.
Production-ready UI.

Semantic Bridge

Semantic Snapshot, Query & Act

Exposes up to 100 controls by stable ref (c1, c2…), queries select/filter choices without opening popups, and runs semantic actions (setValue, toggle, submit).

Policy Guard

Permission Gate & Confirmation Policy

Global AllowPolicy or per-call gate with ConfirmRequired flags to approve or block consequential actions before execution.

Privacy First

Observe Stream & Secret Redaction

Unified ObservedChange stream (Agent/User source) where Password and OneTimeCode fields are always redacted as [redacted].

WebMCP + Undo

WebMCP JS Assets & UndoStack<T>

Ships _content/Lux.Agent/lux-agent.js + lux-behaviors.js for WebMCP and a bounded generic UndoStack<T> in Lux.Agent.Core (NativeAOT).

Two-Layer TanStack Architecture

Headless Core vs Blazor & MAUI UI

Lux.Agent · AgentBridgeService & UndoStack<T>Core · NativeAOT
using Blux.UI.Tools;

agent.RegisterForm(form, confirmSubmit: true);
agent.RegisterDashboard(dashboard);

// Inspect choices accent-insensitively without opening any popup
var choices = agent.Query(new AgentQueryRequest { Within = "region", Text = "Europe" });

// Execute semantic steps with policy checks & automatic secret redaction
var result = await agent.ActAsync([
    new AgentActStep("project name", "setValue", ["Atlas"]),
    new AgentActStep("region", "setValue", ["eu-west"])
]);
wwwroot/lux-agent.js · Browser WebMCP BridgeUI · Blazor & MAUI
// Served automatically via _content/Lux.Agent/lux-agent.js
const snap = window.Blux.agent.snapshot();
const res  = await window.Blux.agent.act([
  { ref: 'Project name', action: 'setValue', args: ['Atlas'] }
]);

// Privacy-preserving observation stream (passwords auto-masked as "[redacted]")
const stop = window.Blux.agent.observe(evt => console.log(evt));
